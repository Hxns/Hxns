### 🛡️ `home-soc-siem-azure` — SOC Lab en Azure
> Laboratorio de Security Operations Center desplegado en la nube. Recolección de logs, correlación de eventos y detección de amenazas en un SIEM. / *Cloud-based SOC lab: log collection, event correlation, and threat detection in a SIEM.*
>
> `Azure` `SIEM` `Splunk` `Threat Detection`

### ☁️ `aws-network-security` — Ciberseguridad de Red en AWS
> Arquitectura de red segura en AWS: segmentación con VPC y subredes, firewalls (Security Groups + pfSense), DMZ y alta disponibilidad de base de datos. / *Secure network architecture on AWS: VPC segmentation, layered firewalls, DMZ, and database high availability.*
>
> `AWS` `VPC` `pfSense` `Network Segmentation`

### 🏠 `homelab-infrastructure` — Mi Homelab
> Entorno centralizado sobre Proxmox para experimentación: red aislada de víctimas, stack de Blue Team (Splunk, Suricata, Wireshark, Zeek) y arsenal de Red Team (Metasploit, Nmap, Burp Suite). / *Centralized Proxmox homelab: isolated victim network, full Blue Team stack and Red Team toolkit.*
>
> `Proxmox` `Docker` `Suricata` `Splunk` `Kali`

### 🔍 `TFM-Auditoria-Ciberseguridad` — Auditoría Técnica (TFM)
> Auditoría técnica de seguridad de la aplicación CRM Krayin en un entorno virtualizado, como Trabajo Fin de Máster. / *Technical security audit of the Krayin CRM application in a virtualized environment (Master's thesis).*
>
> `Pentesting` `OWASP` `Web Security` `Audit`
